全平台自動推廣 30 分鐘設定指南

你的系統已支援 Telegram、LINE、Facebook、Instagram、X、Threads、Dcard、小紅書自動發布。照下面步驟把每個平台的認證申請好、貼進後台，排程器就會自動替你發文。

0先懂流程（30 秒）

  1. 你到 後台 → 平台連線設定，把每個平台的 token／帳號密碼貼上、儲存。
  2. 系統偵測到已連線平台 → 到 自動推廣儀表板，AI 生文、勾選平台、排時間、發布。
  3. 排程器每分鐘自動檢查，時間到了就發布到所有已勾選平台。全自動，之後你只負責「偶爾看看成效」。

1Telegram（5 分鐘）

💬 抓你現成的 bot

最簡單，不用申請。你原本就有一個 bot。
⚠️ 資安步驟：你的舊 bot token 之前寫死在程式碼裡（已修）。請務必到 @BotFather 重新 /newbot 產生新 token，舊的即失效，然後：
① Render 後台 → 你的服務 → Environment → 加 TELEGRAM_BOT_TOKEN=<新 token> ② 也在 平台連線設定 貼一份。

2LINE（5 分鐘）

💬 LINE Messaging API

  1. 到 LINE Developers 登入 → 建立 Provider → 建立 Messaging API Channel。
  2. 取得 Channel Access Token（Messaging API 頁籤 → Issue）。
  3. 貼進 平台連線設定 → LINE。

3Facebook 粉絲頁（10 分鐘）

📘 Page Access Token

  1. 到 Meta Developers 建立 App（類型選 Business）。
  2. App → 新增「Facebook Login for Business」，設權限 pages_manage_posts、pages_read_engagement。
  3. 用 Graph API Explorer → 選你的粉絲頁 → Generate Access Token（長效）。
  4. 貼進 平台連線設定 → Facebook。

4Instagram（10 分鐘）

📸 Instagram 商業帳號＋Meta Graph API

  1. IG 帳號轉成商業帳號（設定 → 帳號類型 → 切換到商業）。
  2. 在 Meta Developers 同一個 App，用 Graph API Explorer 選你的 IG Business Account。
  3. 產生 token（需要 instagram_basic、instagram_content_publish 權限）。
  4. 貼進後台。（IG 貼文需附圖片，文字-only 會失敗）

5X / Twitter（10 分鐘）

🐦 X API

  1. 到 X Developer Portal → 升級到 Free 計畫。
  2. 建立 App → Keys and tokens：API Key、API Secret、Access Token、Access Secret 四個全拿。
  3. 四格都貼進 平台連線設定 → X。

6Threads（5 分鐘）

🧵 帳號密碼直連

用瀏覽器自動化登入發文。不用申請 API。
注意：填你 Threads 的帳號（username）與密碼到 平台連線設定 → Threads。系統自動登入貼文。建議先用測試帳號試 1-2 次。
上次的 Threads 登入 session 若失效，只需重新儲存一次密碼。

7Dcard、小紅書（5 分鐘）

🪪 帳號密碼直連

同樣用瀏覽器自動化。填 Email/帳號＋密碼即可。
法規提醒：社群平台多數禁止自動發文，且可能要求驗證碼（首登會擋）。請用「個人自用小帳」低頻發布（每天 1-2 篇），並以真人客服補充。若平台偵測到異常可能封鎖帳號，後果自負。

8全部填完之後（2 分鐘）

  1. 到 自動推廣儀表板，確認「已連線平台」列出你要的。
  2. 勾選平台 → AI 生成 → 設定發布時間 → 發布。
  3. 回「已排程/已發布」看狀態，失敗會顯示原因。
💡 黃金節奏建議：每個平台每天 1-2 篇、錯開時間，內容用 AI 批量生產（日曆排程一次排一週）。
完成後 = 你的「AI 內容系統」每天都在替你發文到全世界。
