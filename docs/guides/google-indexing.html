免費讓 Google 收錄你的網站

這是所有免費推廣裡唯一會累積、不會歸零的一條路：別人在 Google 搜到你，你不用再花錢買流量。這篇是給台灣一人公司的 10 分鐘設定步驟，不需要寫程式、也不用花錢。

先講結論：搜尋引擎不會自己知道你的網站存在。你要做兩件事——①證明這站是你的（Search Console 驗證）、②交出入口地圖（sitemap）。做完之後，新文章與新頁面會被自動發現。

第 1 步：新增網站資源（免費）

  1. 開啟 search.google.com/search-console，用 Google 帳號登入。
  2. 左側選「網址前綴」型別，輸入 https://lewislunora.onrender.com/（要有 https 與尾斜線）。
  3. Google 會給你一個驗證方式。選「HTML 標記」最簡單：把整行 <meta name="google-site-verification" content="…"> 貼進首頁 <head>。
把上面那行 meta 交給我，我可以直接幫你插到首頁，10 秒完成。也可以自己貼在 <title> 下方第一行。

第 2 步：提交 sitemap（關鍵動作）

  1. Search Console 左側「網站資訊檢索」→「Sitemap」。
  2. 輸入 https://lewislunora.onrender.com/sitemap.xml 按提交。
  3. 狀態顯示「成功」就完成了。之後你每次新增頁面（例如新的職人筆記），都會被這份 sitemap 帶進來。
為什麼這步最重要：沒有 sitemap，Google 只能靠連結自己爬，而你的網站是單頁應用（內容由 API 動態產生），爬蟲看不到那些內頁。sitemap 是你把入口一次交清楚的方式。

第 3 步：讓重要頁面單獨被收錄

「網站資訊檢索」→「網址檢查」→貼上網址 →按「要求索引」。優先順序：

優先網址為什麼
1/品牌主頁，決定你被點進來的標題與摘錄
2/guides/長文集中處，最容易被搜到「維運／備份／AI 自動化」這類關鍵字
3/thoughts/每日更新的職人筆記，長尾流量來源
4/govdata政府開放資料分析，屬低競爭關鍵字
5/novels.html每日連載小說，帶回 daily readers

第 4 步：免費再加速（Bing / IndexNow）

Bing 也接受同一份 sitemap，而且索引速度通常比 Google 快。它們的免費即時通知協定叫 IndexNow：

  • 申請一組 IndexNow key（免費、信箱驗證即可）。
  • 把 key 檔放到網站根目錄，之後每次發布新文章就 POST 通知 Bing，幾分鐘內可被收錄。

想要我接上 IndexNow 就跟我說（需要你提供 key，其餘我寫）。

第 5 步：確認有被收錄（1～3 天）

  • Search Console 左側「成效」→ 用「查詢」看曝光與點擊。
  • 或在 Google 搜尋 site:lewislunora.onrender.com，列出已被收錄的頁面。

第 6 步：讓被收錄的頁面真的排得上（關鍵字）

每個頁面的 <title> 與 meta description 要像「有人在搜這句話」，而不是像公司公告。例：

  • ❌「翔川 Neo｜AI 自動化解決方案」
  • ✅「資料庫備份還原失敗怎麼辦｜完整排查步驟｜翔川 Neo」

本站的職人筆記就是照這個原則命名（一篇一個明確搜尋詞），這是免費自然流量最快累積的內容來源。
