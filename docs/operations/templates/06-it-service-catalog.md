# IT 服務目錄 (IT Service Catalog)

> **用途**：讓全公司知道 IT 提供什麼服務、申請方式、SLA 標準
> **適用範圍**：全公司
> **文件版本**：v1.0

---

## 目錄

| 服務分類 | 說明 |
|----------|------|
| 1. 基礎設施服務 | 伺服器、VM、儲存、網路 |
| 2. 帳號與權限服務 | 入職/離職帳號申請 |
| 3. 開發維運服務 | CI/CD、容器、代碼管理 |
| 4. 資訊安全服務 | 弱點掃描、資安事件 |
| 5. 資料服務 | 資料庫、備份、資料分析 |
| 6. 終端使用者服務 | 設備、VPN、Email |
| 7. 雲端服務 | AWS / Azure / GCP 資源申請 |

## SLA 通則

| 等級 | 回應時間 | 解決時間 | 適用範圍 |
|------|----------|----------|----------|
| **P1（重大）** | 15 分鐘 | 2 小時 | 核心服務中斷、對外網站掛掉 |
| **P2（嚴重）** | 30 分鐘 | 4 小時 | 部分功能異常 |
| **P3（一般）** | 4 小時 | 24 小時 | 單一使用者問題 |
| **P4（低）** | 1 工作天 | 5 工作天 | 詢問、建議 |
