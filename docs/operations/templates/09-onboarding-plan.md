# 新人訓練計畫 (Onboarding Plan)

> **用途**：新進維運/SRE/DevOps 工程師標準化訓練
> **適用範圍**：維運部
> **訓練週期**：4 週（可依經驗調整）
> **文件版本**：v1.0

---

## 訓練總覽

| 週次 | 主題 | 目標 |
|------|------|------|
| Week 1 | 環境熟悉與基礎知識 | 了解公司架構、系統拓樸、基本操作 |
| Week 2 | 日常工作流程 | 熟悉 Incident、Change、SOP 流程 |
| Week 3 | 獨立作業能力 | 能獨立處理 P3 事件、執行例行任務 |
| Week 4 | 值班準備與考核 | 通過值班資格考試，可獨立 On-call |

## Week 4：值班資格

### 值班資格考核

- [ ] 通過 Incident 模擬測驗（P1 情境演練）
- [ ] 了解值班 On-call 流程與 Escalation 路徑
- [ ] 熟悉 PagerDuty / OpsGenie 值班工具操作
- [ ] 獨立完成一次值班交接

### P1 模擬情境

```
情境：早上 8:00 收到告警「官網 502 Bad Gateway」
問題：
1. 你會怎麼排查？
2. 第一步做什麼？
3. 怎麼判斷是 app / DB / network 問題？
4. 什麼時候要通報主管？
5. 什麼時候要啟用 DR 流程？
```

```
情境：收到資安通報「DB 疑似被注入」
問題：
1. 如何確認是否被入侵？
2. 隔離措施怎麼做？
3. 通報流程？
4. 證據保存？
```

## Mentor 制度

| 角色 | 職責 |
|------|------|
| 部門主管 | 指派 Mentor、審核訓練進度 |
| Mentor | 一對一指導、審核任務完成度、值班考核 |
| 新人 | 主動學習、每天填寫學習日誌 |

### Mentor 規範

- 每位 Mentor 同時最多帶 2 位新人
- 每週五與新人進行 30 分鐘 1-on-1
- 訓練結束後提交新人評估報告
