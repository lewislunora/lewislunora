## 三、客戶追蹤表（100 家電商名單）

> 用 Google 試算表或 Excel 建一欄，欄位如下。複製貼上即可。

| 欄位 | 說明 |
|------|------|
| 店名 | 店家名稱 |
| 平台 | 蝦皮/官網/粉專 |
| 聯絡管道 | Email / LINE / Messenger |
| 聯絡人 | 老闆或小編姓名 |
| 具體觀察 | 你看到的痛點（例：粉專常被問庫存） |
| 首次發送日期 | 幾號發出 |
| 狀態 | 已發/已回/已談/簽約 |
| 追蹤日期1 | +3 天（發新的具體內容） |
| 追蹤日期2 | +1 週 |
| 追蹤日期3 | +1 個月 |
| 備註 | 任何進展 |

### 找客戶的管道（免費）
1. Google 搜「[電商品牌] 台灣」+ 找出他們官網/粉專
2. 蝦皮/露天搜尋熱門賣家，看誰沒有自動客服
3. 臉書/IG 搜「[產業] 賣家」社團
4. 用「[產品類型] + 賣家」找出中大型店家（比較付得起 30K-60K）

### 每天要做的事（30 分鐘）
- 每天挑 3-5 家，寫「具體觀察」＋發訊息
- 追蹤過去的訊息（3 天/1 週/1 月）
- 回覆的趕快排 15 分鐘通話

## 四、通話腳本（15 分鐘評估）

1. **寒暄＋聆聽**（5 分）：問他「目前回訊息最花時間的是什麼？」「有沒有漏單過？」
2. **對症下藥**（3 分）：連結他的痛點 → 你做的 AI 客服能怎麼解
3. **展示**（3 分）：開你的提案/demo 給他看
4. **報價＋下一步**（4 分）：給報價，問「你要不要我先幫你評估，裝這個值得不值得？」（**不要急著推，先給價值**）

---

## 五、關鍵心法（記住這三條）

1. **量少質精**：每週 5-10 封「用心客製」遠勝 200 封亂槍打鳥。
2. **別怕不回應**：50% 以上的案子是在「跟進」時成交的，不是第一次。3 天/1 週/1 月用「新的具體內容」追。
3. **先給價值再談錢**：第一封訊息別推銷，先講具體觀察＋具體成效。
