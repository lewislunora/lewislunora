一、Python 程式邏輯題
Q1. 在 Python 中執行 0.1 + 0.2 == 0.3，結果是 True 還是 False？
直覺上 0.1+0.2 應該等於 0.3，但電腦是怎麼計算的呢？
顯示解答
答案是 False！電腦以二進位儲存十進位小數，0.1 無法被精確表示， 所以 0.1 + 0.2 = 0.30000000000000004。
正確比較方式：
round(0.1 + 0.2, 1) == 0.3 → True
import math; math.isclose(0.1 + 0.2, 0.3) → True
Q2. 執行以下程式後，a 的內容是什麼？
a = [1, 2, 3]
b = a
b.append(4)
b 是 a 的「複製」還是「參照」？
顯示解答
a 變成 [1, 2, 3, 4]。
變數存的是「記憶體參照」，b = a 讓兩者指向同一個串列， 改 b 等於改 a。要真正複製請用 b = a.copy() 或 b = list(a)。
Q3. 2 ** 3 ** 2 的結果是？
指數運算是左結合還是右結合？
顯示解答
答案是 512。指數運算是右結合： 2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512。
Q4. 用一行 Python 反轉字串 "abc"。
提示：利用「切片（slice）」的步進參數。
顯示解答
"abc"[::-1] → "cba"
步進 -1 表示由右往左取值；也可用 "".join(reversed("abc"))。
Q5. 寫一個函式判斷數字是否為質數。
質數：大於 1，且只能被 1 和自己整除。想想看可以檢查到「根號 n」就好。
顯示解答
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True
檢查到 √n 就足夠，因為若有因數，必然一對中小於等於 √n。
二、邏輯推理謎題
Q6. 有兩個水桶：7L 與 3L，無刻度。如何量出剛好 5L 的水？
只能裝滿、倒空、互相倒入，不能目測。
顯示解答
7L 裝滿 → 倒入 3L 桶（7L 剩 4L）→ 倒掉 3L 桶 → 再倒入 3L（7L 剩 1L）→ 倒掉 3L 桶 → 倒入 1L（3L 桶有 1L）→ 7L 裝滿 → 倒入 3L 桶補滿（只倒 2L）→ 7L 桶剩 5L ✅
Q7. 三門問題（Monty Hall）：主持人知道車在哪一門。選 A 後，主持人打開沒有車的 B 門，問你要不要換到 C 門？
換門的勝率是 1/2 還是 2/3？
顯示解答
應該換！換門勝率 2/3，不換只有 1/3。 初始選中車的機率 1/3；當你選中車時，主持人可開兩扇門任選；當你選空門時（機率 2/3）， 主持人被迫開出唯一另一扇空門，剩下的那扇門就是車。所以「換」只在初始選中車時才輸。
Q8. 用 3、3、8、8 四個數字算出 24（四則運算，每個數字只能用一次）。
顯示解答
8 ÷ (3 − 8 ÷ 3) = 24
因為 8 ÷ 3 = 2.666…，3 − 2.666… = 0.333…，8 ÷ 0.333… = 24。
Q9. 一天 24 小時內，時針與分針「完全重疊」幾次？
顯示解答
22 次。每 12 小時重疊 11 次（12:00 那一次算在跨週期）， 24 小時 = 2 × 11 = 22 次。
Q10. 房間裡至少要有幾個人，才使「至少有兩人生日相同」的機率超過 50%？（生日悖論）
顯示解答
23 人。看似只要 183 人（一年的一半），但兩兩組合數是 C(23,2)=253 對， 計算互不相同的機率 (365/365)×(364/365)×…，23 人時不到 50%。
