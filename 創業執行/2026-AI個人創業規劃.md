## 五、執行步驟

### 第 1 週：奠定基礎

```
□ 建立服務頁面
□ 更新 LinkedIn 檔案
□ 準備作品集
□ 設定收款方式
```

### 第 2-4 週：獲取客戶

```
□ 發布 LinkedIn 內容 (每週 3 篇)
□ 加入相關社團
□ 主動聯繫潛在客戶
□ 提供免費諮詢
```

### 第 2-3 月：交付服務

```
□ 完成首個專案
□ 收集客戶評價
□ 請求轉介紹
□ 優化服務流程
```

### 第 4-6 月：擴展

```
□ 開發自動化工具
□ 建立 SOP
□ 考慮雇用更多人
□ 開發產品
```
