## 二、UI/UX 設計風格

### 視覺風格

```
主色調：柔和粉彩色
├──  основний: #FFB6C1 (淺粉紅)
├──  secondary: #E6E6FA (薰衣草紫)
├──  accent: #98FB98 (薄荷綠)
└──  background: #FFF5F5 (米白)

字體：圓潤友好
├── 標題: 粗體圓體
└── 內文: 柔和黑體

圖標：手繪風格、植物元素
```

```
✓ 圓角柔和 (24px)

✓ 動效輕盈
✓ 無壓迫感
```
