========================================
Day 4 — Line 官方帳號設定
========================================

一、申請 Line OA
====================
1. 前往 https://manager.line.biz/
2. 用你的 Line 帳號登入
3. 點「建立新帳號」
4. 填寫：
   - 帳號名稱：翔川 Neo｜曜科技 AI 客服
   - 說明：AI 智能客服 · 自動內容生成 · 品牌 App
   - 大頭貼：可以使用品牌 Logo
   - 類別：IT / 科技
5. 選擇「免費方案」即可開始


二、基本設定
====================
1. 點頭像 → 「帳號設定」
   - 狀態訊息：24 小時 AI 智能客服，立即體驗 →
   - 連結網址：https://lewislunora.github.io/lewislunora/

2. 點頭像 → 「回應設定」
   - 開啟「自動回應訊息」
   - 關閉「加入好友時的回應」（我們用下面的歡迎訊息代替）

五、加入好友 QR Code
====================
1. 在 Line OA 後台 → 「加入好友」→ 下載 QR Code
2. 把 QR Code 放在：
   - 商品頁的聯絡區塊
   - FB 貼文附圖
   - Email 簽名檔


六、串接我們的 AI 客服（進階）
====================
當你準備好要把 AI 客服綁到 Line OA 上時，
我們可以透過 Line Messaging API 串接：

1. Line Developers Console → 建立 Provider → 建立 Channel (Messaging API)
2. 取得 Channel Access Token 和 Channel Secret
3. 設定 Webhook URL（指向你的 telegram-bot.py 或新的 webhook endpoint）

我可以在 30 分鐘內幫你完成設定。
需要時跟我說一聲。
