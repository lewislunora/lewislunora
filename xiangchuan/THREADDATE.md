# ThreadDate — 交友 App 產品概念

## 核心哲學

> 「從對話開始，不是從外表開始。」

ThreadDate 結合 **Threads 的對話質感 × Facebook 的社交網絡 × Dcard 的匿名安全感**，創造一個「先聊再認識」的交友體驗。

---

## 三大平台強項對照

| 功能 | Threads | Facebook | Dcard | ThreadDate 融合 |
|------|---------|----------|-------|-----------------|
| 互動形式 | 串文討論、文字為主 | 社團、活動、動態 | 匿名看板、投票 | **匿串 + 實名社群雙軌制** |
| 身份 | 可公開可小帳 | 實名社交圖譜 | 完全匿名 | **漸進式揭面**（匿名→配對成功→可選擇揭露） |
| 媒合機制 | 內容推薦演算法 | 共同朋友、興趣社團 | 看板分類、卡稱 | **話題深度 + 社交共圈** 雙重匹配 |
| 認識門檻 | 低（追蹤即可互動） | 中（加好友才能深入） | 極低（完全匿名） | **極低切入，逐步加深** |

## 產品架構

### 三層模式（由淺入深）

```
┌─────────────────────────────────────────┐
│           匿串廣場 (Threads)             │
│  匿名發文、討論、投票，純內容互動        │
│  不顯示個人檔案，只看見「串」             │
├─────────────────────────────────────────┤
│           共圈社群 (Dcard)               │
│  學校/公司/興趣圈，可選匿名或實名        │
│  社團活動、主題板討論                     │
├─────────────────────────────────────────┤
│           約會模式 (Facebook)            │
│  配對成功後進入 Dating Mode              │
│  共同活動、共同好友、真實自我介紹        │
└─────────────────────────────────────────┘
```

---

## 核心功能詳解

### 1. 匿串廣場（Threads 基因）

- 以「話題串」為單位，不是以「人」為單位
- 每串有主題標籤，例如 `#台北美食探索` `#深夜哲學` `#獨立音樂`
- 演算法推薦**與你價值觀相近的串**，而不是正妹帥哥
- 在一串中互動多次後，系統提示「你們聊得來，要配對嗎？」

### 2. 共圈社群（Dcard 基因）

- 學校圈、公司圈、興趣圈三種社群圈
- 每個圈有自己的看板，可匿名發文
- 匿名帖下方互動良好者，可「敲碗」相互揭露
- **卡稱系統**：在特定看板可固定暱稱但不暴露真實身份

### 3. 活動約會（Facebook 基因）

- 串聯 real-world 活動：讀書會、爬山、品酒、看展
- 配對成功後可共同報名活動作為「第一次約會」
- 共同好友網絡可查詢（二度社交驗證）
- 實名認證使用者有「藍勾勾」，增加信任度

## 獨特配對機制

### 「對話深度分」取代顏值分

```
配對分數 = 串互動次數 × 話題多元性 + 共圈重疊度 + 情緒共鳴指標
```

- 不用滑照片，而是看對方在哪些串的發言打動你
- 支援「一段話自我介紹 + 語音條」取代 9 宮格照片

### 漸進式揭面（Progressive Disclosure）

```
階段 1：匿串 → 只看見文字與想法
階段 2：共圈 → 顯示學校/公司/興趣標籤（無照片）
階段 3：配對 → 雙方同意後，才交換真實照片與姓名
階段 4：約會 → 解鎖完整社群檔案、共同好友
```

## Tech Stack 建議（MVP）

```
Frontend: React Native (iOS/Android)
Backend: Node.js + Express + PostgreSQL
Real-time: WebSocket (串討論即時更新)
AI: LLM 萃取話題關鍵字 + 配對演算法
Auth: Apple ID / Google / 手機號（可選）
匿名層: 端到端加密 + 隨機 ID 輪換
```

## 和現有交友 App 的差異

| | Tinder | Bumble | Dcard 交友 | ThreadDate |
|--|--------|--------|-----------|------------|
| 第一印象 | 照片 | 照片+自我介紹 | 匿名卡 | **你的文字想法** |
| 配對方式 | 滑 | 滑 | 卡配對 | **話題契合度** |
| 深度 | 淺 | 淺-中 | 中 | **深（漸進式）** |
| 安全感 | 低 | 中 | 高（匿名） | **高（可控揭露）** |
| 社群感 | 無 | 弱 | 強（看板） | **極強（三層社群）** |
